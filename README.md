# Takeoff Engine Platform

منصة ويب عربية للقياس الهندسي وتقدير الكلفة في مشاريع البناء. يركز الإصدار الحالي على مسار قابل للاستخدام: إنشاء مشروع، فتح صفحة قياس، معايرة الرسم، قياس Area وLinear وSegment وCount، احتساب الكميات وتقديرها، ثم حفظ الحالة واستعادتها.

## الحالة الحالية

هذا المستودع ينفذ **MVP ويب أولاً**. تستند قرارات المجال إلى حزمة بحث ومعمارية مستقلة موثقة في `docs/`. تظل التطبيقات الأصلية لـWindows وAndroid، وإدخال PDF/DWG/DXF المتقدم، والأتمتة والذكاء الاصطناعي ضمن مراحل التوسع اللاحقة؛ ولا تُقدَّم كميزات مكتملة هنا.

## البنية

| المسار | الغرض |
|---|---|
| `client/` | تطبيق React ومساحة عمل القياس |
| `server/` | إجراءات tRPC وطبقة البيانات |
| `shared/takeoff-core/` | نواة هندسة وقياس حتمية مستقلة عن الواجهة |
| `drizzle/` | مخطط البيانات وهجرات قاعدة البيانات |
| `docs/` | خطة البناء وقرارات الدراسة والملاحظات التنفيذية |
| `architecture/` | قرارات ومواد معمارية مستقلة |
| `tests/` | fixtures وgolden data المخصصة للمراحل التالية |
| `examples/` | عينات استخدام غير حساسة |
| `scripts/` | مهام التطوير والقياس |

## التشغيل محلياً

```bash
pnpm install
pnpm dev
```

تتطلب مسارات المشاريع حساباً عبر Manus OAuth وقاعدة بيانات مضبوطة من بيئة المشروع. بعد توفر البيئة، افتح `/projects` وأنشئ مشروعاً جديداً.

## الفحص والاختبارات

```bash
pnpm check
pnpm test
```

## مبادئ هندسية

- تحفظ الهندسة في `DrawingSpace`، ولا تحسب الواجهة الكميات مستقلة.
- لا يظهر طول أو مساحة بلا نموذج مقياس صالح.
- يمثل Area وLinear وSegment وCount سلوكيات مجال مستقلة.
- يسجل الحفظ الحالة المنظمة للمشروع؛ ولا تعتمد الكميات على حالة React المؤقتة وحدها.
- لا تستخدم الصيغ أو الاستيراد مستقبلاً تنفيذ كود غير موثوق.
