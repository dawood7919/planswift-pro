# دليل تكامل PDF ومساحة القياس — BHR

يجمع هذا الدليل بين الاختبارات الحتمية ومعاينة BHR الحية. طبقة PDF لا تستخدم تحويلاً مستقلاً؛ بل تستورد `createPdfViewportMatrix` و`formatCssMatrix` من نواة `viewport.ts` نفسها التي تمثل تحويل مساحة القياس.

| الدليل | ما يثبته |
|---|---|
| اختبارات `pdfViewportTransform.test.ts` | مصفوفة التحويل الحتمية للإزاحة والتكبير ومطابقة التحويل بين أبعاد PDF وSVG. |
| اختبار نجاح `pdfPlanLayer.ui.test.ts` | تحميل صفحة PDF محاكية، ضبط أبعاد canvas إلى 320×480، رسم الصفحة، اختفاء حالة التحميل، ووجود CSS matrix مشتركة. |
| اختبار فشل `pdfPlanLayer.ui.test.ts` | تنبيه عربي مرئي وزر «إعادة محاولة العرض» بعد تعذر التحميل. |
| معاينة BHR | صفحة PDF الفعلية والصور المصغرة السبع ظهرت بعد اكتمال التحميل في معاينة مساحة العمل، بما فيها عرض الهاتف 375×812. |

المعاينة الحية تثبت ظهور الوثيقة خلف شبكة ومساحة القياس. أما تحريك المخطط وتكبيره فيمرران نفس متغيري `zoom` و`pan` إلى طبقة PDF وإلى طبقة الرسم، وتتحقق اختبارات المصفوفة من تطابق التحويل الناتج.

> لا يمثل هذا الدليل بديلاً عن اختبار لمس يدوي لكل أجهزة المستخدم، لكنه يثبت مسار التحميل الناجح والفشل والتحويل المشترك بطريقة قابلة للمراجعة.
