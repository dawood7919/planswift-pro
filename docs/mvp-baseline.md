# خط أساس MVP — Takeoff Web

## النطاق المعتمد

يمثل هذا المستودع **MVP ويب أولاً** لمنصة قياس مخططات وتقدير كميات عربية. لا يدّعي هذا الخط الأساس تكافؤاً كاملاً بعد مع PlanSwift؛ بل يثبت مجموعة عملية قابلة للتدقيق لفتح مشروع، تحميل المخططات، معايرة القياسات، حفظها، وتصدير تقاريرها.

| المجال | ضمن خط الأساس | دليل التحقق |
|---|---|---|
| المشاريع والملكية | إنشاء وفتح وحفظ واستيراد/تصدير ولقطات إصدار غير مدمرة | إجراءات tRPC محمية واختبارات ملكية المشروع والقوالب والإصدارات |
| صفحات ومخططات PDF | استيراد PDF متعدد الصفحات، صفحة فارغة، ترتيب وتسمية وحذف آمن، تكبير وتحريك | `docs/pdf-integration-evidence.md` ومعاينة BHR |
| القياس الحتمي | Area وLinear وSegment وCount وRoof Area وVolume، معايرة وسياقات مقياس، التقاط وتحقيق هندسي | اختبارات النواة الهندسية و`snapping.test.ts` |
| الإنتاجية | بحث محلي، تحديد متعدد، نسخ وحذف وإزاحة جماعية قابلة للتدقيق | اختبارات DOM لمساحة العمل ومحول الإزاحة |
| التقدير | Parts وAssemblies وصيغ آمنة بتشخيصات ووحدات | `docs/template-formulas.md` واختبارات الصيغ والواجهة |
| التقارير | جدول كميات وتقدير وCSV وExcel وطباعة عربية | اختبارات التقرير وExcel والطباعة |
| المراجعات | Overlay لنسختي PDF وسجل مراجعات محفوظ | اختبارات مطابقة الوثائق والصلاحيات وتدفق الواجهة |

## التحقق الحالي

فحوص النوع وبناء الإنتاج ناجحة، وتشغّل الحزمة **76 اختبار Vitest**. تم التحقق بصرياً من PDF الخاص بمشروع BHR بعد التحميل ومن مساحة العمل على عرض 375×812؛ ويشرح `docs/mobile-workspace-verification.md` الفرق بين معاينة BHR الحية والتفاعل المحاكى في DOM.

> المسارات المحمية تعتمد جلسة Manus OAuth. اكتمل التحقق الآلي للحراس والملكية، لكن اختبار اللمس على جهاز فعلي ومسار OAuth في VPS يحتاجان بيئة حسابات وأسرار مرحلة مخصصة.

## ما هو خارج هذا الخط الأساس

| الموضوع | الحالة | المسار الآمن التالي |
|---|---|---|
| Windows وAndroid/S Pen | غير منفذ كمنتج أصلي | تحديد طبقة مشاركة للنواة ثم اختيار تطبيق سطح مكتب وتطبيق Android بعد تثبيت API واتفاقية ملفات مشتركة |
| تبعيات القوالب | غير مدعومة عمداً | رسم بياني صريح للتبعيات مع كشف دورات وتقييم مرتب، بدلاً من توسعة النص التنفيذي للصيغة |
| تشغيل VPS للمسارات المحمية | غير مفعّل | توفير OAuth وDatabase وStorage مستقلة للمرحلة في ملف أسرار محلي خارج المستودع |
| تدقيق لمس الأجهزة | غير منفذ | جلسة اختبار على جهاز هاتف/قلم فعلي بعد تجهيز التطبيق الأصلي أو PWA الاختبارية |

## مصفوفة المراجعة

تسرد `docs/mvp-verification-matrix.md` كل مجال رئيسي في قائمة التنفيذ، ودليله الفعلي، وقيده المتبقي. استخدمها مع `todo.md` عند مراجعة أي نقطة تحقق كي لا يُعامل قيد مستقبلي كميزة مكتملة.

## قرار الاعتماد

يمكن استخدام هذا الإصدار كخط أساس MVP للويب للقياس والتقدير والتدريب الداخلي، مع الإبقاء على التحقق البشري قبل اعتماد أي مخرجات تكلفة أو مستندات تعاقدية. أي توسيع للمنصات أو للخدمات المحمية يجب أن يحافظ على التحويل الهندسي الحتمي وملكية المشاريع وملف المشروع المتحقق كما هي موثقة هنا.
