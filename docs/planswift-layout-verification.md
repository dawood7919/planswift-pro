# تحقق تخطيط سطح عمل PlanSwift

أظهرت معاينة BHR عند عرض سطح مكتب عريض تخطيطاً مكتبياً عملياً يتكون من شريط أوامر علوي، وشجرة صفحات وقياسات يساراً، وعمود أدوات هندسية، ومساحة مخطط مركزية، ولوحة مفتش وخصائص يميناً. ظهرت صفحات PDF الحقيقية في الشجرة، وظهر ملف PDF في مساحة الرسم، مع استمرار أدوات القياس والمعايرة والتعليق ضمن السطح الجديد.

لا تهدف الواجهة إلى نسخ علامات PlanSwift أو شعاره أو العناصر المحمية الخاصة به؛ بل تعتمد **بنية سير العمل** نفسها وتبقي هوية Takeoff العربية وحساباته وتخزينه المستقلين.
