# تحقق البيئة المرحلية المحمية على VPS

**تاريخ التحقق:** 20 أغسطس 2026. يصف هذا المستند بيئة اختبار مستقلة تخص Takeoff فقط. لا توجد فيه أي قيم سرية أو روابط وصول عامة أو بيانات من قاعدة الإنتاج.

## النطاق والعزل

تعمل المرحلة من إصدار مستقل تحت `/home/ubuntu/takeoff-stage/releases/d2c1255e`، ويشير `current` إلى هذا الإصدار. استُخدمت قاعدة بيانات MySQL وMinIO خاصتان بمرحلة Takeoff مع volumes وشبكة باسم `takeoff_stage_*` و`takeoff_stage_network`. بقيت الخدمات الموجودة مسبقاً خارج هذا المشروع ولم تُعدَّل.

| الضابط | النتيجة المتحققة |
|---|---|
| منفذ التطبيق | التطبيق يستمع على `127.0.0.1:4179` فقط. |
| قاعدة البيانات | `takeoff-stage-db` مستقلة وصحية، وتُطبَّق الهجرات داخل حاوية منفصلة. |
| تخزين الملفات | `takeoff-stage-minio` غير مربوط بمنفذ مضيف عام؛ bucket المرحلة خاص. |
| ملف التشغيل الحساس | ملف أسرار تشغيل المرحلة خارج المصدر وبصلاحية `600`. |
| التخزين في المتصفح | وكيل التطبيق يعيد الملف من MinIO عبر التطبيق نفسه في المرحلة، فلا يتلقى العميل اسم مضيف MinIO الداخلي. |

## ما تم تشغيله والتحقق منه

أُنشئت الخدمات، ثم نُفِّذت الهجرات. خضعت النسخة في حاوية Node 22 لفحص الأنواع والاختبارات والبناء بنجاح قبل تشغيل التطبيق. بعد تحسين وكيل التخزين، استُخدم بناء محلي متحقق ونُقل ناتج الإنتاج فقط إلى الإصدار المرحلي لتجنب ضغط الذاكرة على VPS الصغير أثناء استمرار خدمات MySQL وMinIO.

| التحقق | النتيجة |
|---|---|
| الصفحة الرئيسية للتطبيق | `200` عبر loopback. |
| قائمة المشاريع من دون جلسة | `401`، كما يجب للمسار المحمي. |
| جلسة مرحلة محدودة إلى 15 دقيقة | نجحت بعد إنشاء مستخدم اختبار في قاعدة بيانات المرحلة فقط. |
| مسار `auth.me` وقائمة المشاريع | أعادا المستخدم والمشاريع المملوكة لجلسة المرحلة. |
| إنشاء مشروع محمي | نجح داخل قاعدة بيانات المرحلة المستقلة. |
| معايرة وقياس مساحة | حُفظت معايرة 100:10 م وعنصر مساحة متعدد الرؤوس، ثم استُعيدت مساحة العمل مع العنصر والصفحة المحفوظين. |
| استيراد PDF صغير صالح | أنشأ وثيقة وصفحة داخل المشروع التجريبي وحفظ الملف في MinIO. |
| تنزيل PDF عبر `/manus-storage/*` | أعاد `200` و`application/pdf` وتوقيع `%PDF-` من دون إعادة توجيه. |

## حدود التحقق المقصودة

جلسة المرحلة الموقعة أداة تحقق خادم محلية فقط؛ مدتها 15 دقيقة، ولا تضيف مسار تجاوز أو إعداداً إلى التطبيق المنشور. لم يُختبر تدفق Manus OAuth الخارجي في VPS لأن مفاتيحه وخدمة الهوية المُدارة لم تُنسخ إلى الخادم. لذلك يثبت الاختبار **حماية الجلسة، ملكية قاعدة البيانات، الترحيلات، التخزين، واستيراد/عرض PDF** في بيئة مستقلة، ولا يدّعي اعتماد مزود الهوية المُدار على VPS.

> قبل جعل المرحلة متاحة لمستخدمين حقيقيين، يلزم ربطها بمزود هوية مرحلي معتمد وواجهة HTTPS مناسبة. البيئة الحالية متعمدة العزل على loopback ومخصصة للتحقق التشغيلي فقط.

## التشغيل اللاحق

يحتوي `ops/vps/docker-compose.stage.yml` على ملفات الخدمات. يبدأ المسار المعتاد بالتحقق، ثم الهجرة، ثم profile التطبيق. لا تُحفظ الأسرار في مستودع المشروع، ولا يُستخدم `docker system prune` أو volumes عامة عند صيانة هذه المرحلة.
