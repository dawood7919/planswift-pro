# القياس المتكرر وعامل التكرار

يمثل **عامل التكرار** عدداً موجباً يطبق على عنصر قياس واحد عندما تتكرر الوحدة نفسها في المخطط، مثل نافذة نموذجية أو غرفة متطابقة. تحفظ المنصة هندسة الوحدة المرجعية مرة واحدة، ثم تضرب الكمية المشتقة منها في العامل؛ لا تنسخ نقاطاً أو تضيف عنصراً خفياً.

| الحقل | القاعدة |
|---|---|
| القيمة الافتراضية | `1` لجميع العناصر الحالية والجديدة. |
| المجال المقبول | عدد موجب حتى أربع منازل عشرية. |
| كمية التقرير | `الكمية الهندسية × عامل التكرار`. |
| تكلفة القالب وبنود المكتبة | تستقبل كمية التقرير المركبة قبل تقييم الصيغ والمواد والعمالة والهالك. |
| التدقيق | يسجل اعتماد القيمة أمراً من نوع `SET_TAKEOFF_MULTIPLIER`. |

يبقى العامل ضمن عنصر القياس عند الحفظ، ويظهر في ملف المشروع ولقطة الإصدار، مع توافق استيراد ملفات أقدم لا تحتوي عليه عبر افتراض القيمة `1`. لذلك تبقى النسخ القديمة قابلة للاستعادة من دون تغيير كمياتها.
