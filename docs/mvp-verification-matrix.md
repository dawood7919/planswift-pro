# مصفوفة تحقق MVP — Takeoff Web

تربط هذه المصفوفة مجالات قائمة التنفيذ الأساسية بالأدلة القابلة للمراجعة. الحالة **متحقق** تعني أن التنفيذ يملك اختباراً أو معاينة موثقة؛ ولا تعني أن الميزة تغطي كل توسعات المنتج المستقبلية.

| المجال في قائمة التنفيذ | الحالة | الدليل القابل للمراجعة | القيد أو المتابعة |
|---|---|---|---|
| صفحة الهبوط ومسار الدخول | متحقق | `server/homeContent.test.ts` ومعاينات سطح المكتب والهاتف | لا يوجد قيد MVP مباشر |
| المشاريع والملكية | متحقق | `server/projects.router.test.ts` و`server/templateOwnership.test.ts` | يعتمد الدخول الحي على Manus OAuth |
| الرسم والمعايرة والقياسات الأساسية | متحقق | `server/takeoffCore.test.ts` واختبارات DOM لمساحة العمل | يحتاج المستخدم مراجعة القياس قبل القرار التعاقدي |
| قطوع المساحات والتحرير الهندسي | متحقق | اختبارات النواة الهندسية ومحول `server/translate.test.ts` | لا توجد أدوات CAD ثلاثية الأبعاد |
| PDF والصفحات والتحويل | متحقق | `docs/pdf-integration-evidence.md` و`server/pdfPlanLayer.ui.test.ts` | اختبار لمس يدوي لكل جهاز منفصل |
| المراجعات المرئية | متحقق | `server/documentReview.test.ts` وسجل مراجعات المشروع | يقتصر على وثائق PDF المرتبطة |
| الالتقاط والشبكة | متحقق | `server/snapping.test.ts` | لا يوجد OCR/auto-count |
| القياسات المتخصصة وتعدد المقاييس | متحقق | `server/takeoffCore.test.ts` واختبارات مسارات وسياقات المقياس | لا توجد طبقات قياس CAD أصلية |
| القوالب والصيغ | متحقق ضمن MVP | `server/formula.test.ts` و`docs/template-formulas.md` | تبعيات القوالب الصريحة غير مدعومة عمداً |
| التقارير والتصدير | متحقق | `server/report.test.ts` و`server/reportExcel.test.ts` و`server/printReport.test.ts` | لا يوجد تكامل ERP مؤسسي |
| النسخ والإصدارات | متحقق | `server/projectFile.test.ts` واختبارات مسارات الإصدارات | لا تضمّن النسخ ملفات PDF أو القوالب الخاصة |
| البحث وإنتاجية التحرير | متحقق | `server/itemSearch.test.ts` و`server/workspaceSearch.ui.test.ts` | لا يوجد مساعد ذكاء اصطناعي |
| الاستجابة والهاتف | متحقق ضمن الويب | `docs/mobile-workspace-verification.md` واختبار DOM 375px | لا يوجد اختبار لمس على جهاز فعلي |
| VPS المرحلي | متحقق للفحص غير المحمي | `docs/vps-health-2026-08-19.md` و`docs/vps-staging-runbook.md` | تشغيل OAuth/DB/Storage المحمي يحتاج أسرار مرحلة مستقلة |
| Windows وAndroid/S Pen | غير منفذ | موثق كخارج خط الأساس في `docs/mvp-baseline.md` | يتطلب برنامجاً أصلياً أو PWA مدروسة وإدارة قلم |

> تمثل صفوف **متحقق** البنود المنجزة في قائمة التنفيذ حتى خط الأساس الحالي. تبقى القيود الواردة في العمود الأخير بنوداً مفتوحة ومقصودة، ولا تُخفى باعتبارها مكتملة.
